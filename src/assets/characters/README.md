# 캐릭터 초상화

이 폴더에 이미지를 넣으면 다음 빌드부터 자동으로 게임에 적용된다. 설정 파일을 고칠 필요는 없다.

| 파일명 | 인물 |
|---|---|
| `jung.png` | 정강사 (오전 AI 교육 강사) |
| `jo.png` | 조강사 (오후 리더십 교육 강사) |
| `park.png` | 박피엠 (사내 교육운영 PM) |
| `lee.png` | 이과장 (외부 교육대행업체 담당자) |
| `choi.png` | 최본부장 (교육 참가자 대표) |
| `kim.png` | 김상무 (경영기획 담당 임원) |
| `player.png` | 탐정 (플레이어) |

- 형식: png / jpg / webp
- 구도: 상반신, 세로형(약 4:5, 예: 800×1000), 얼굴이 위쪽 1/3 부근
- 배경: 투명 또는 어두운 단색
- 실존 인물을 닮지 않은 가상의 얼굴을 쓴다.

적용되는 곳:
- 대화창 왼쪽 위 초상화 카드
- 맵 위 캐릭터(얼굴을 원형으로 자른 토큰)
- 역할 배지, 최종 추론 보드의 인물 선택

맵 토큰에서 얼굴이 치우쳐 잘리면 `src/data/portraits.json` 에 인물별 값을 넣어 조정한다.

```json
{ "default": { "cx": 0.5, "cy": 0.33, "size": 0.62 }, "kim": { "cy": 0.3, "size": 0.55 } }
```
